# Phase 1 Summary — Baselines (CreditCard Fraud)

## Goal
Build a reproducible baseline pipeline and compare two models fairly using the same fixed 70/15/15 (train/val/test) split.

## Dataset
- creditcard.csv (highly imbalanced fraud dataset)
- Split: stratified 70/15/15 with seed = 42 (saved and reused for every run)

## Models trained
- Logistic Regression (StandardScaler + class_weight="balanced")
- XGBoost (XGBClassifier + scale_pos_weight from train split)

## Metrics used (why)
- PR-AUC: better than accuracy for imbalanced fraud data
- Recall at fixed precision (0.10 and 0.20): controls false-alert rate
- Precision@1000 and FraudFound@1000: simulates reviewing top 1000 alerts
- Inference speed: ms/row and rows/sec (real-time practicality)

## Key findings (Phase 1)
- XGBoost achieved higher PR-AUC than Logistic Regression on both validation and test.
- Precision@1000 and FraudFound@1000 were similar across the two models in this run.
- Logistic Regression is much faster per transaction, but XGBoost is still fast enough for many near-real-time settings.
